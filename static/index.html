Dual-Engine Multimodal Architecture

How NLP semantic embeddings and structural lexical URL features combine for unified threat defense.

1. Natural Language Intent Engine (DistilBERT) PyTorch + HuggingFace

Fine-tuned 6-layer Transformer with 66M parameters. Tokenizes email subject headers and message bodies into sub-word tokens with position embeddings. Captures social engineering urgency, fake credential requests, impersonation, and coercive semantics.

2. Lexical & Structural URL Security Engine (DNN) TensorFlow / Keras 3

Extracts 49 offline numeric features: Shannon entropy of domain and path, brand keyword count, suspicious TLD match, IPv4 host detection, URL shortener detection, character ratio distributions, and subdomain nesting. Classifies through 3 Dense layers (128 → 64 → 32) with Dropout (0.3) and Batch Normalization.

3. Multimodal Decision Fusion & Override Gate Bayesian Noisy-OR Fusion

When an email contains embedded hyperlinks, the system extracts every link and evaluates them in parallel. If any link demonstrates high-confidence malicious traits (P_url ≥ 0.85), an override flag is triggered regardless of benign email wording. Otherwise, probabilistic fusion combines threat vectors:

P_combined = 1 - (1 - P_email) × (1 - max(P_urls))
